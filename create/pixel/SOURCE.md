# 像素小画家：制作与来源

画布复用 [Konva](https://github.com/konvajs/konva) 10.7.0（MIT），与本站小画板共用本地发行文件，没有新增依赖或运行时 CDN。

- 发行文件：`../../draw/vendor/konva-10.7.0.min.js`
- 完整许可证：`../../draw/vendor/LICENSE-Konva.txt`
- 发行来源及固定版本：`../../draw/SOURCE.md`

Konva 提供画布、图形、指针事件和缩放。像素矩阵、画笔及橡皮、连贯拖画、撤销与重做、8/16 格选择、爱心与花朵图案、草稿验证、1024×1024 PNG 导出和与本站相册的连接由本站制作，不是从其他像素编辑器复制的完整应用。

图案由本站用小格子自行设计；不使用外部图片、字体或音频。作品和草稿只保存在当前浏览器，下载图片可独立留存。
