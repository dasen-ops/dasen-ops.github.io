# Dyson的小小空间

个人小站，包含小游戏、创作角、小相册和闲聊文章。

## 打开和试玩

双击本目录的 `index.html` 即可打开。新增页面的游戏和组件资源都在本地，不需要安装软件。

- 水果贪吃蛇：保留原来的在线入口与排行榜。
- 2048 · 数字合合乐：方向键、手机滑动或页面箭头，支持最高分与本机存档。
- 记忆方格：三个难度，先记住亮格，再点出位置。
- 彩虹打砖块：鼠标、方向键或手机拖动控制挡板，可暂停、重玩、关闭声音。
- 推箱子：七个关卡，支持方向键、手机方向按钮与滑动；可以撤销、重玩和选关，完成记录保存在本机。
- 四子棋：和电脑下或两人轮流下，电脑有三个水平，支持点列与键盘落子。
- 数字滑块：把 1–8 按顺序排好，入门和挑战的题目都可解；可撤销、重玩与换题。
- 小小数独：三个水平的 9×9 数独，提供数字键盘、提示和撤销；题目已核验唯一解，未完成的草稿可继续。
- 花园扫雷：看数字找到安全格，手机用“翻开／标记”切换操作；第一格和周围格子保证安全，提供入门和挑战。
- 小画板：画笔、橡皮、颜色、贴纸、撤销和 PNG 保存。草稿只保存在当前设备浏览器。
- 小相册：真实游戏截图，可放大、切换和缩放。
- 像素小画家：8×8 或 16×16 格涂画，支持画笔、橡皮、撤销和图案，导出 1024×1024 PNG 或存到本机相册。
- 小小节奏机：三种合成音色、八拍格子、播放与停止、速度和音量；可记住草稿、下载和重新打开节奏文件。
- 闲聊：三篇独立文章，可从首页及“再读一篇”进入。

## 整合功能

- 首页可按名称查找游戏、收藏喜欢的游戏、查看最近玩过、本机最高分或完成次数；在另一标签页更新记录，首页会同步显示。
- 游戏、画板、相册和文章共用站内导航，随时可以返回首页或换个地方逛逛。
- 画板“存到相册”把作品保存在当前浏览器，最多 12 张；相册可放大、下载和删除作品。
- 收藏和画作不会上传，也不跨设备同步。清除浏览器数据会移除记录，重要画作请下载留存。
- 记忆方格在锁屏或切换应用时重新准备，避免看不到题目时继续计时。
- 创作角新增“积木小路线”：使用 Blockly 拼接方向与重复积木，运行三条路线；积木草稿和完成星星在本机保留。手机也有点按添加入口。
- 积木挑战、记忆方格和 2048 成功时使用 canvas-confetti 撒花；开启系统“减少动画”时不播放撒花。

## 页面布局

- 首页使用清楚的欢迎区和分区导航；九款小游戏在电脑上三列，平板两列，手机一列。
- 创作入口单独成区，相册和文章在电脑上并排展示；各页面共用柔和的绿色、卡片和按钮样式。
- 手机主要按钮至少 44 像素高，积木页面可以在路线与拼接区之间快捷跳转，2048 的方向键整齐排成一行。
- 节奏机只在点击播放后开启声音；停止、离开页面或切到后台时停止。导出文件保存的是节奏格子、速度和音量，不是录音。

## 内容与来源

复用项目固定版本，本地保留许可证和 `SOURCE.md`。完整说明见 `credits.html`；新增游戏不使用外部广告、统计脚本或运行时 CDN。

相册图片放在 `album/images/`。文章源文件放在 `articles/content/`，由本地 Marked 生成静态 HTML；修改文章后，助手使用已有 Node 运行 `scripts/build-articles.cjs` 即可，不需要安装依赖。文章不依赖浏览器实时读取 Markdown，双击也能打开。

本次未建立账号、在线画作上传或多游戏公共排行榜。新增游戏最高分和画板草稿保存在当前设备浏览器里。
