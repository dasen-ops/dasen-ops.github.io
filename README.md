# Dyson的小小空间

个人小站，包含小游戏、创作角、小相册和闲聊文章。

## 打开和试玩

双击本目录的 `index.html` 即可打开。新增页面的游戏和组件资源都在本地，不需要安装软件。

- 水果贪吃蛇：保留原来的在线入口与排行榜。
- 2048 · 数字合合乐：方向键、手机滑动或页面箭头，支持最高分与本机存档。
- 记忆方格：三个难度，先记住亮格，再点出位置。
- 彩虹打砖块：鼠标、方向键或手机拖动控制挡板，可暂停、重玩、关闭声音。
- 小画板：画笔、橡皮、颜色、贴纸、撤销和 PNG 保存。草稿只保存在当前设备浏览器。
- 小相册：真实游戏截图，可放大、切换和缩放。
- 闲聊：两篇独立文章，可从首页进入。

## 内容与来源

复用项目固定版本，本地保留许可证和 `SOURCE.md`。完整说明见 `credits.html`；新增游戏不使用外部广告、统计脚本或运行时 CDN。

相册图片放在 `album/images/`。文章源文件放在 `articles/content/`，由本地 Marked 生成静态 HTML；修改文章后，助手使用已有 Node 运行 `scripts/build-articles.cjs` 即可，不需要安装依赖。文章不依赖浏览器实时读取 Markdown，双击也能打开。

本次未建立账号、在线画作上传或多游戏公共排行榜。新增游戏最高分和画板草稿保存在当前设备浏览器里。
